## X post (tag @NousResearch, attach the demo video)

I built Tironian for the Hermes Agent plugin hackathon.

A lot of what I ask Hermes is the same few jobs. Tironian notices that, trains a small model for each one from my own sessions, tests it on conversations it has never seen, and only then lets it answer. If it's ever unsure, my usual model answers instead.

Your own small model, learned from your work.

https://tironian.vercel.app
