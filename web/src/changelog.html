Nov 6, 2026

Fixes found on real data

Before spending anything on a real training run, the whole pipeline was run against real Hermes sessions. Three problems turned up and were fixed:

  • The trainer's environment was set up with Hermes's own Python paths visible, so it skipped installing Modal's dependencies and would have failed on its own. Every trainer call now gets a clean environment.
  • Sessions captured live were imported a second time from history, which could put the same conversation in both the training and the test data. They are now skipped, and earlier duplicates removed.
  • Grouping split one task into many small families because folder names and file types counted as differences. They are now placeholders, common synonyms are merged, and words shared by most requests are ignored.
Nov 6, 2026

Desktop page and status-bar chip

A Tironian page in Hermes Desktop: requests learned, answered locally, saved, each task family with its test result, live training progress, and buttons to train, shadow, promote or stop a model. Training always shows the example counts and cost first.

Nov 6, 2026

Tested on a real Hermes install

  • hermes plugins validate and doctor pass, including the security scan.
  • Live capture recorded every step of real streaming turns, with tool outcomes and schemas.
  • A small model answered a real Hermes turn through the middleware. When Hermes blocked its command, the usual model took over and finished the task.
  • From that test: any failed or blocked tool step now hands the rest of the turn back to your usual model.
Nov 5, 2026

0.1.0, first version

Capture with redaction, deterministic grading, task families, the Hermes function calling exporter, training on Modal or a local GPU, the held-out test with a Wilson lower bound gate, shadow and live routing with validation and silent fallback, the /tironian command and the hermes tironian CLI. 54 tests.
